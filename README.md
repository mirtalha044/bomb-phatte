# Bomb Phatte 💣

A single-file cartoon prank website with a fuse intro, burning-canvas reveal, and scroll-linked animated avatar encounters with a bomb, tank, and drone.

## Preview locally

Open `index.html` in a web browser. No install, backend, or build command is required.

## Publish via GitHub Pages

1. On [GitHub](https://github.com/new), create a **public** repository named `bomb-phatte` under your account (`mirtalha044`).
2. Upload `index.html` and `.nojekyll` from this folder to the **root** of the new repository, then commit them to the `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Choose `main` and `/ (root)`, then click **Save**.
4. GitHub will display the published site URL when deployment is successful. It is expected to be `https://mirtalha044.github.io/bomb-phatte/` but **is not live until the repo and Pages are created/enabled**.

The repository URL will be `https://github.com/mirtalha044/bomb-phatte` once created.

## Files

- `index.html` — complete standalone site, ready for GitHub Pages
- `.nojekyll` — prevent Jekyll processing for this static site

No external libraries or image assets are required.
